# 透明反馈

## 1. 读取和调用反馈

读取 `AGENTS.md`、阶段规则、专项规范或内置方法时，在读取前或读取时简短说明：

```text
读取规则【<相对路径>】，用于：<用途>
```

调用内置方法时说明：

```text
使用内置方法 <方法名>：<用途>
```

本 Skill 已内置 Superpowers 方法，不得把不存在的外部调用写成已调用。

## 2. 交付汇总

- 当前阶段、Work Item 和 Feature；
- 读取的规则、规范和状态；

- 完成和未完成的内容；
- 修改文件或明确说明未修改；
- 已执行、未执行和无法执行的验证；
- 剩余风险、阻塞和需要用户确认的事项。
- 测试命令、实际结果、证据路径、失败归因和受影响的 `requirement-*`。
