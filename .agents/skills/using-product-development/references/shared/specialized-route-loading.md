# 专项规范读取

## 1. 规则来源

产品或团队特定的“阶段 × 子领域 -> 规范路径”只从当前仓库的 `AGENTS.md` 专项路由获取。不存在时不得凭经验虚构路径。

## 2. 读取步骤

1. 识别当前阶段和子领域；
2. 读取 `AGENTS.md` 中的适用路由；
3. 读取命中的需求、方案、接口、代码、测试、文档或发布规范；
4. 按透明反馈规则说明路径和用途；
5. 发现与协作规则冲突时，停止并说明冲突。

没有专项规范时，说明“当前任务无专项规范依据”，再按通用规则、真实源码和真实脚本执行，并在交付中标记。

## 3. 禁止事项

- 不按文件名相似度猜专项规范；
- 不把外部方法默认流程当作仓库规范；
- 不把其它产品规则套入当前仓库；
- 不因专项规范缺失而补写未经确认的事实。
